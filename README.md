# Биржа учебных проектов

Учебное консольное приложение для поиска и обмена проектами между студентами.
Текущая версия развивает сценарий ПР1: проверяет готовность проекта и показывает
его данные перед размещением на бирже.

## Возможности

- загрузка списка учебных проектов из JSON;
- показ и поиск проектов;
- добавление и удаление проектов по ID;
- сортировка готовых проектов по названию;
- простая статистика по доступности проектов;
- сохранение данных в JSON;
- простое консольное меню;
- обработка отсутствующего и некорректного JSON-файла.

## Структура проекта

```text
main.py                 запуск и меню
project_logic.py        проверки и обработка проектов
project_data.py         загрузка и сохранение JSON
data/projects.json      данные предметной области
tests/test_project.py   основные pytest-тесты
```

## Запуск

```powershell
.\.venv\Scripts\Activate.ps1
python main.py
```

В меню доступны показ проектов, сохранение данных и выход.

## Тесты

```powershell
python -m pytest -q
```
