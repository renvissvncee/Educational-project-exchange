# Биржа учебных проектов

Учебное консольное приложение для поиска и обмена проектами между студентами.
Версия ПР3 использует объектную модель предметной области и сохраняет данные
в прежнем JSON-формате.

## Возможности

- загрузка списка учебных проектов из JSON;
- показ и поиск проектов;
- добавление и удаление проектов;
- сортировка готовых проектов по названию;
- простая статистика по доступности проектов;
- сохранение данных в JSON;
- простое консольное меню;

## Структура проекта

```text
models/
├── __init__.py         экспорт Project и Student
├── projects.py         класс Project и функции работы с коллекцией
└── students.py         класс Student
main.py                 запуск и меню
project_logic.py        публичный импорт функций логики
project_data.py        загрузка и сохранение JSON
data/projects.json      данные предметной области
tests/test_project.py   тесты объектной модели
```

## Основной класс

`Student` представляет студента и хранит `id` и `name`.

`Project` представляет учебный проект. Его атрибуты: `id`, `student`, `name`,
`participants`, `ready` и `publication_date`. Поле `student` содержит объект
`Student`. Методы `__str__()`, `can_be_published()`, `from_data()` и `to_data()`
отвечают за представление, проверку готовности и преобразование данных.

Функции работы с коллекцией находятся в `models/projects.py`, а JSON остаётся
отдельной ответственностью `project_data.py`:

```text
JSON -> Project
Project -> JSON
```


## Запуск

python main.py

В меню доступны показ, поиск, добавление и удаление проектов, статистика,
сохранение данных и выход.
