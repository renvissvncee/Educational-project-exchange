# Биржа учебных проектов

## Сервис для поиска и обмена учебными проектами между студентами.

Приложение позволяет студентам обмениваться учебными проектами, находить интересные проекты и делиться своими наработками.

## Целевая аудитория

Целевой аудиторией являются студенты, которые хотят найти учебные проекты для изучения, обмена опытом и совместной работы.

## Предметная область

Предметная область включает в себя процессы поиска и обмена учебными проектами между студентами.

## Основные сущности

- Студент: студент, который использует сервис для поиска и обмена учебными проектами.
- Проект: учебный проект, который студент может найти или поделиться с другими студентами.
- Команда: группа студентов, которые работают над учебным проектом вместе.
- Заявка: запрос студента на участие в учебном проекте или на обмен проектами.

## Основные функции

- Регистрация и авторизация студентов;
- Поиск учебных проектов по различным критериям;
- Просмотр информации о проекте и его авторах;
- Возможность отправки заявки на участие в проекте или на обмен проектами;

## План развития

- разработка веб-приложения;
- подключение базы данных;
- реализация пользователей;
- разработка API;
- контейнеризация приложения;
- настройка CI/CD.
